# AI Chat Widget (в стиле Jivo)

Фронтенд чата ИИ-агента: плавающий виджет в правом нижнем углу и демонстрационная
страница магазина, на которой он виден в контексте. Чистый HTML/CSS/JS — без сборки
и зависимостей.

## Как запустить

Просто откройте `index.html` в браузере (двойной клик). Скрипты подключены обычными
тегами `<script>`, поэтому всё работает и по `file://`.

Если хочется локальный сервер:

```bash
# Python
python -m http.server 5173

# или Node
npx serve .
```

Затем откройте http://localhost:5173

## Структура

```
index.html                 демонстрационная страница + подключение скриптов
styles/demo.css            стили демонстрационной страницы
styles/chat-widget.css     стили виджета чата
src/chatWidget.js          логика виджета (window.AIChatWidget)
src/app.js                 инициализация виджета и витрины
src/mock/mockChat.js       ВСЕ мок-данные (агент, сообщения, ответы, товары)
```

## Возможности виджета

- Круглая кнопка-лаунчер с пульсацией и счётчиком непрочитанных.
- Окно чата: шапка с аватаром и статусом агента, сворачивание и закрытие.
- Лента сообщений с аватарами, временем и статусами доставки (✓ / ✓✓).
- Индикатор набора текста («печатает…»).
- Быстрые ответы (чипы) под лентой и внутри сообщений.
- Поле ввода с автоувеличением, отправка по Enter (Shift+Enter — перенос строки).
- Панель эмодзи и прикрепление файлов.
- Звуковой сигнал на ответ агента (можно выключить кнопкой в шапке).
- Автооткрытие «приглашения» через 9 секунд (имитация Jivo).
- Мобильная раскладка: на узких экранах чат разворачивается на весь экран.

## Мок-данные

По правилу проекта (`AGENTS.md`) все временные данные вынесены в отдельный слой —
`src/mock/mockChat.js` и помечены `// TODO: заменить на реальные данные`.

Что там лежит:

- `mockAgent`, `mockOperator` — профили агента и оператора;
- `mockMessages` — приветственная лента;
- `mockQuickReplies` — быстрые ответы;
- `mockKnowledgeBase` + `mockFallback` — «мозг» ассистента (подбор ответа по ключевым словам);
- `mockEmojis`, `mockAttachments` — панель эмодзи и файлы;
- `mockProducts`, `mockFeatures`, `mockStats`, `mockNav` — контент демо-страницы.

Чтобы подменить данные — отредактируйте только `mockChat.js`. Когда появится реальный
бэкенд, замените `matchIntent`/`replyTo` в `src/chatWidget.js` на вызов API.
